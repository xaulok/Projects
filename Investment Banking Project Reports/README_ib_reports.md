# 🏦 Investment Banking Project Reports

> Financial modelling and deal analysis following IB conventions — DCF, comps, and LBO frameworks.

---

## 📌 Objective

This folder contains financial analysis reports modelled after the work produced in Investment Banking divisions. Each report applies core IB valuation methodologies to real or hypothetical companies, with the aim of building technical proficiency in the tools and frameworks used in live deal environments.

---

## 🛠️ Tools & Frameworks

| Category | Tools |
|----------|-------|
| Financial Modelling | Microsoft Excel (Advanced), Python |
| Valuation Methods | DCF, Comparable Company Analysis (Comps), Precedent Transactions, LBO |
| Data Sources | Bloomberg Terminal, Forage Simulations, Public Filings |
| Presentation | PowerPoint, PDF Reports |

---

## 📁 Reports Included

| Report | Methodology | Description |
|--------|------------|-------------|
| DCF Valuation | Discounted Cash Flow | 5-year FCF projection, WACC estimation, terminal value (Gordon Growth + EV/EBITDA exit) |
| Comparable Company Analysis | Trading Comps | EV/EBITDA, P/E, EV/Revenue multiples across peer set |
| LBO Model | Leveraged Buyout | Entry/exit assumptions, debt waterfall, IRR sensitivity analysis |
| M&A Analysis | Merger Model | Accretion/dilution analysis, synergy estimation |

---

## 🔍 Key Concepts Applied

- **WACC Calculation** — Cost of equity (CAPM), cost of debt, capital structure weights
- **Terminal Value** — Gordon Growth Model vs. EV/EBITDA exit multiple approach
- **Sensitivity Tables** — Two-variable data tables (WACC × growth rate, entry multiple × leverage)
- **LBO Returns** — IRR analysis at 3/5/7-year exit horizons
- **Accretion/Dilution** — EPS impact of stock vs. cash M&A deals

---

## 📊 Forage Background

These models were informed by completing **10 virtual investment banking simulations** via Forage, including:

- Bank of America · JPMorgan · Goldman Sachs
- Fidelity · PNC Financial Services

Each simulation covered deal structuring, financial statement analysis, client presentation, and IB-specific Excel modelling.
