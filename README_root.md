## 🧠 Project Summaries

### 🐦 Twitter Sentiment Analysis
> **Domain:** NLP · Financial Sentiment  
Scraped and analysed Twitter data to classify market sentiment (bullish / bearish / neutral) around financial assets. Built a sentiment pipeline using VADER and TextBlob, and visualised sentiment trends against price movements.

📁 [`/Twitter Sentiment Analysis`](./Twitter%20Sentiment%20Analysis) · Python · NLP

---

### 💳 Credit Risk Analysis
> **Domain:** Risk Management · Banking  
Modelled the probability of loan default using real-world lending data. Applied logistic regression and tree-based classifiers, with feature engineering on credit history, income ratios, and delinquency flags.

📁 [`/Credit Risk Analysis`](./Credit%20Risk%20Analysis) · Python · Classification

---

### 📉 Customer Churn Prediction
> **Domain:** Predictive Analytics · CRM  
Predicted customer churn for a telecom dataset using supervised ML. Focused on class imbalance handling (SMOTE), feature importance, and business interpretation of churn drivers.

📁 [`/Customer Churn Prediction`](./Customer%20Churn%20Prediction) · Python · ML

---

### 🏦 Investment Banking Project Reports
> **Domain:** IB · Corporate Finance  
Built financial models including DCF, comparable company analysis (comps), and LBO frameworks. Reports follow standard IB deal-room conventions.

📁 [`/Investment Banking Project Reports`](./Investment%20Banking%20Project%20Reports) · Excel · Python

### 📈 Portfolio Optimization
> **Domain:** Quantitative Finance · Asset Allocation  
Implemented Modern Portfolio Theory (Markowitz) to construct the efficient frontier across a basket of equities. Optimised for the maximum Sharpe ratio and minimum volatility portfolios.

📁 [`/Portfolio Optimization`](./Portfolio%20Optimization) · Python · scipy

---

### 🔮 Sales Forecasting
> **Domain:** Time Series Econometrics  
Applied Box-Jenkins methodology (ARIMA/SARIMA) to forecast monthly sales. Included ADF stationarity tests, ACF/PACF correlograms, and model diagnostics (Ljung-Box, residual plots).

📁 [`/Sales Forecasting`](./Sales%20Forecasting) · Python · statsmodels

---

### 📊 Stock Price Fluctuation
> **Domain:** Equity Research · Market Analysis  
Analysed historical volatility, return distributions, and price momentum for selected equities. Includes rolling Sharpe ratio analysis and drawdown visualisations.

📁 [`/Stock Price Fluctuation`](./Stock%20Price%20Fluctuation) · Python · yfinance
